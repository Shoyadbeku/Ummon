# Stanislav Petrov: YouTube montaj

`matn.txt` dagi hikoyaga mos YouTube kliplaridan ovozsiz va subtitrsiz montaj (1920×1080, ~7 daq 25 s).
Har bir abzas o'qilish davomiyligiga teng vaqt oladi, shuning uchun ustiga o'z ovozingizni qo'yish oson.

## Ishga tushirish (o'z kompyuteringizda)

```bash
pip install -U yt-dlp      # ffmpeg ham o'rnatilgan bo'lishi kerak
python3 montaj.py           # natija: petrov_montaj.mp4
```

Klipni almashtirish uchun `reja.json` da `id` (YouTube video ID) yoki `s` (boshlanish soniyasi) ni o'zgartiring va qayta ishga tushiring; yuklanganlar `kesh/` da saqlanadi.

> Diqqat: bu kliplar mualliflik huquqi bilan himoyalangan. YouTube'ga joylasangiz, Content ID da'vosi yoki ogohlantirish bo'lishi mumkin.
