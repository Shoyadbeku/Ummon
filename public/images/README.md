# AI rasmlar (ixtiyoriy)

Rasmni `public/images/<sahna-id>.png` (yoki `.jpg`, `.jpeg`, `.webp`) nomi bilan saqlang —
masalan `03-hot-plov.png`. Rasm topilsa, sahnadagi vektor illyustratsiya o‘rniga
Ken Burns (sekin zoom + panorama) va parallaks bilan ko‘rsatiladi.

Tavsiya: 16:9, kamida 1920×1080, matnsiz. Promptlar: `npm run assets -- --prompts`
yoki `src/data/script.ts` dagi `imagePrompt` maydonlari.
