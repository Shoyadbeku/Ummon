# Ovoz fayllari (voiceover)

Har bir sahna uchun alohida fayl: `<sahna-id>.wav` (yoki `.mp3`, `.m4a`, `.aac`, `.ogg`).

| Fayl | Matn |
|---|---|
| `01-hook.wav` | Ovqat sovidi, surat hali tayyor emas! |
| `02-intro.wav` | Restoranga ovqat yeyishga keladi-yu, avval palovga fotosessiya uyushtiradigan odamlarni bilasizmi? |
| `03-hot-plov.wav` | Issiq palov keldi, bug‘i chiqib turibdi. Hamma qoshiq olishga tayyor! |
| `04-stop.wav` | Birdan bittasi baqiradi: — To‘xtanglar! Hali suratga olmadim! |
| `05-photoshoot.wav` | Tepadan, yonidan, go‘shtini yaqinlashtirib… Keyin selfi, musiqa, joylashuv! |
| `06-waiting.wav` | Do‘stlar ochlikdan kutib o‘tiribdi, palov esa sovib qoldi. |
| `07-passport.wav` | Shunda bittasi so‘raydi: — Do‘stim, ovqat yeymizmi yoki palovga pasport tayyorlaymizmi? |
| `08-posted.wav` | Nihoyat, surat internetga joylandi. Lekin palovning issiqligi allaqachon yo‘qoldi! |
| `09-moral.wav` | Axir palovning eng yaxshi filtri — uning bug‘i, eng zo‘r vaqti esa issiqligida! |
| `10-question.wav` | Rostini ayting, siz avval ovqatlanasizmi yoki suratga olasizmi? |

Avtomatik yaratish: `npm run voiceover` (Gemini TTS, `GEMINI_API_KEY` kerak).
Fayl qo‘shilgach, video davomiyligi o‘zi qayta hisoblanadi.
