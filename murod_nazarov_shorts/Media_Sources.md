# Media manbalari va litsenziyalar

Faqat foydalanishga ruxsat berilgan materiallar ishlatildi. Ijtimoiy tarmoqlardagi (YouTube, X, Facebook, VK, Rutube, Mover.uz, Reddit) videolar **ishlatilmadi**: ular mualliflik huquqi bilan himoyalangan va ochiq litsenziyasi yo‘q. Pexels/Pixabay API kalitsiz bu muhitdan yopiq edi. Murod Nazarovning shaxsiy fotosuratlari ham ishlatilmadi (ochiq litsenziyali surati topilmadi); uning o‘rniga stok-odamni u sifatida ko‘rsatmaslik uchun ism kartasida siluet/kran kadri ishlatildi.
